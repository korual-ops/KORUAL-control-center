# KORUAL Traffic Engine

윤리적인 SEO·콘텐츠·UTM·전환 데이터를 축적해 성과가 좋은 채널과 주제를 반복 확대하는 코루알 유입 엔진입니다. 봇 트래픽, 자동 클릭, 스팸 게시를 만들지 않습니다.

## 핵심 루프

1. 채널별 UTM 링크 생성
2. 세션·주문·매출·비용 수집
3. 순이익 기반 채널 점수 계산
4. 성과 상위 주제의 후속 콘텐츠 제안
5. 주간 보고서 생성

## 무제한 실행 원칙

- 핵심 분석기는 외부 유료 API가 없는 순수 Node.js 모듈입니다.
- 실행 횟수·사용자 수를 코드에서 제한하지 않습니다.
- 실제 가용량은 GitHub Actions, Vercel, Supabase 요금제의 트래픽·저장용량 한도를 따릅니다.
- 봇 방문, 자동 클릭, 스팸 백링크는 생성하지 않습니다.

## 시작

```bash
npm test
npm run report
```

`SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`는 Vercel 환경변수로만 관리합니다. 서비스 역할 키는 브라우저에 노출하지 않습니다.
