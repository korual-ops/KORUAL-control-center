# Cafe24 AI Commerce 연동 로드맵

## 확인된 공식 경로

1. **Admin API** — 상품·주문·배송의 운영 원본. OAuth 2.0 완료 후 사용합니다.
2. **일반 Webhook + Webhook Logs** — 상태 변경을 실시간 수집하고 누락 이벤트를 복구합니다.
3. **Cafe24 Data Bridge** — 상품 조회, 장바구니 등 고객 행동 이벤트를 실시간 수집합니다.
4. **Global Catalog MCP** — UCP 규격 기반으로 AI 에이전트가 Cafe24 전역 상품 카탈로그를 탐색합니다.

## KORUAL 적용 순서

- 1단계: Admin API OAuth 및 상품·주문 동기화
- 2단계: 웹훅 멱등성 저장과 로그 기반 누락 복구
- 3단계: Data Bridge로 조회→장바구니→구매 퍼널 구축
- 4단계: 핵심 SKU의 정보 품질을 검증한 후 Global Catalog MCP 노출 검토

## 안전 기준

- 주문번호·상품번호·이벤트 ID를 중복 방지 키로 사용합니다.
- 웹훅 본문과 고객 개인정보를 일반 애플리케이션 로그에 남기지 않습니다.
- AI 카탈로그에는 현재 판매가·재고·배송·반품 정책과 일치하는 정보만 제공합니다.
- MCP 및 구조화 데이터 노출은 검색 또는 판매 성과를 보장하지 않습니다.

## 운영 KPI

- 웹훅 수신 성공률
- 누락 이벤트 복구 시간
- 상품번호/SKU 매핑 실패율
- 행동 이벤트→주문 연결률
- AI 카탈로그 유입 주문 비중
