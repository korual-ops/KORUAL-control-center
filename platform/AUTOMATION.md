# KORUAL 자동 운영 설계

KORUAL의 자동 운영 목표는 사람이 반복 업무를 직접 처리하지 않고, AI Agent와 운영 파이프라인이 매출·주문·CS·여행·리포트를 계속 순환시키는 구조를 만드는 것입니다.

## 1. 자동 운영 원칙

초부자 알고리즘 기준:

현금흐름 → 레버리지 → 시스템화 → 자동화 → 자산화 → 네트워크 효과 → 장기복리 → 리스크 차단

KORUAL 자동 운영은 아래 5개 Agent로 시작합니다.

## 2. Agent 구조

### 2.1 Commerce Sourcing Agent

목표: 팔릴 만한 상품을 찾고, 마진을 계산하고, 등록 초안을 생성합니다.

처리 순서:

1. 공급처 상품 수집
2. 원가, 배송비, 플랫폼 수수료 계산
3. 경쟁 판매가 비교
4. 예상 마진 35% 이상 필터링
5. 상세페이지 문구 생성
6. 상표권/KC/통관 위험 체크
7. 업로드 후보 등록

### 2.2 Order Operations Agent

목표: 주문 발생 후 발주, 송장, 지연 알림을 자동화합니다.

처리 순서:

1. 신규 주문 감지
2. SKU와 공급처 매칭
3. 발주 태스크 생성
4. 송장 업데이트
5. 고객 배송 안내
6. 지연 주문 에스컬레이션

### 2.3 Customer Support Agent

목표: 고객 문의를 분류하고 답변 초안을 생성합니다.

문의 분류:

- 배송 문의
- 환불 문의
- 교환 문의
- 상품 정보
- 대량 구매/B2B
- 일반 문의

주의:

- 환불/교환은 약관 기준으로만 답변
- 법적 책임을 인정하는 표현 금지
- 분쟁 가능 문의는 사람에게 에스컬레이션

### 2.4 Travel Planning Agent

목표: 도시 입력만으로 여행 일정과 제휴 수익 기회를 만듭니다.

처리 순서:

1. 목적지/날짜/예산/스타일 입력
2. 항공·호텔·동선·맛집·카페 추천
3. 공항 근처/야간/안 힘든 코스 분리
4. 제휴 링크 삽입
5. 여행 일정표 생성

### 2.5 Finance Report Agent

목표: 매일 현금흐름과 리스크를 요약합니다.

리포트 항목:

- 일매출
- 순이익
- SKU별 마진
- 광고비
- 환불률
- 구독 매출
- 위험 알림
- 다음 액션

## 3. 자동 운영 KPI

- 자동 처리율: 70% → 90% 목표
- SKU당 최소 마진: 35% 이상
- 환불률: 5% 이하
- 고객 문의 1차 응답: 1분 이내
- 일일 현금흐름 리포트: 매일 자동 생성
- 수익 엔진: PB, 드롭쉬핑, SaaS, 여행 제휴, AI 과금

## 4. 실제 연동 순서

1. Supabase/PostgreSQL 연결
2. 상품 테이블, 주문 테이블, 고객 문의 테이블 생성
3. OpenAI API 연결
4. 스마트스토어/쿠팡/카페24 상품 업로드 API 연결
5. 배송/송장 API 연결
6. Slack/Email 알림 연결
7. 결제/구독 시스템 연결
8. 관리자 승인 플로우 추가

## 5. 운영 권한 구조

- Owner: 전체 매출, 결제, API 키, 리스크 관리
- Operator: 상품/주문/CS 처리
- Reseller: 본인 상품/주문/정산 확인
- Partner: 제휴 성과 확인
- Viewer: 대시보드 보기 전용

## 6. 주의할 점

완전 자동 발주와 완전 자동 환불은 초기에 금지합니다. 초기에는 AI가 초안을 만들고 사람이 승인하는 Human-in-the-loop 구조가 안전합니다.

자동화 우선순위:

1. 리포트 자동화
2. CS 초안 자동화
3. 상품 상세페이지 자동화
4. 주문 알림 자동화
5. 발주 자동화
6. 환불/분쟁 처리 보조
