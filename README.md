# KORUAL Control Center

KORUAL Control Center는 커머스, 여행, AI Agent, 비즈니스 운영, 금융, 개발자 API를 하나로 연결하는 KORUAL Super Platform의 관리자/운영 허브입니다.

## v0.2 — KORUAL Life Service Marketplace MVP

이번 버전은 **아정당식 상담/제휴 구조 + 헤이딜러식 경쟁견적 구조**를 KORUAL에 적용한 첫 베타 화면입니다.

핵심 흐름:

```text
고객 서비스 선택
→ 조건/지역/희망일 입력
→ 제휴업체 동시 견적 요청
→ 가격 + 평점 + 후기 + 거리 + 보증 비교
→ 업체 선택
→ 상담/예약
```

현재 화면에서 제공하는 서비스:

- 입주청소
- 이사
- 정수기 렌탈
- 에어컨 청소
- 인터넷/TV
- 줄눈/코팅

### MVP 화면 기능

- 서비스 선택 및 검색
- 지역/희망일/규모 입력
- AI 예상 적정가격 표시 영역
- 업체 경쟁견적 비교
- 평점/후기/거리/서비스 범위/보증 정보 비교
- 업체 선택 및 상담 요청 UX
- 추천 입주 패키지
- 모바일 반응형 UI
- 견적 요청의 브라우저 로컬 저장

> 현재 견적 데이터는 프로토타입용 시드 데이터입니다. 실제 운영 전에는 Supabase DB와 제휴업체/견적 API로 교체해야 합니다.

## v0.1 기존 구성

- Express 기반 Auth API
- JWT 쿠키 인증
- Admin 사용자 관리 API
- 정적 대시보드 UI: `public/index.html`
- 플랫폼 요약 API: `/platform/summary`
- 헬스체크 API: `/health`
- AI 운영봇 핵심 모듈: `ai-bot/korualBot.js`

## AI 운영봇 정책

KORUAL AI Operations Bot은 기본적으로 내부 운영 작업을 자동 승인합니다.

### 자동 승인

- 상품 후보 선별
- 상품 등록 초안 생성
- 광고 카피 초안 생성
- 일일 운영 리포트 생성
- 마진, 전환율, ROAS 분석
- 내부 대시보드용 추천 생성
- 견적 이상치 탐지 및 운영 알림

### 소유자 확인 필요

- 금전 실행
- 예산 변경
- 고객 계정에 직접 영향이 있는 작업
- 공개 발송
- 법무 검토가 필요한 작업
- 외부 서비스 연동
- 실제 예약/결제 확정 정책 변경

운영 원칙은 `진짜 중요한 실행만 컨펌, 나머지는 자동 승인`입니다.

## 장기 방향

KORUAL은 단순 쇼핑몰이 아니라 다음 구조의 플랫폼 기업을 목표로 합니다.

```text
현금흐름 → 레버리지 → 시스템화 → 자동화 → 자산화 → 네트워크 효과 → 장기 복리 → 리스크 차단
```

KORUAL Life Service의 장기 포지션:

> **생활서비스의 가격을 투명하게 만들고, 고객과 검증된 전문업체를 데이터로 연결하는 운영 플랫폼**
